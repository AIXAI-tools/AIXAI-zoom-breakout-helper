# AIXAI-zoom-breakout-helper

Zoom 分組討論室（Breakout Rooms）批次**建立房間、依清單改名**的小工具。

> **非官方聲明**：本專案是第三方個人工具，與 Zoom Communications, Inc. 沒有任何關係，也未獲其背書。「Zoom」為其所有人之商標。

## 它解決什麼問題
臨時開會（例如固定號碼的個人會議室）要分組時，每次都得：建立 N 間房 → 一間一間點「改名」→ 從記事本貼上名字。
Zoom 的 REST API 無法在「進行中的會議」操作分組討論室，所以本工具用**模擬滑鼠與鍵盤**，替你把這些重複動作自動做完。

## 功能
- 房名清單可存多組，切換即用；房間數由清單行數決定
- 建房方式（下拉選擇）：建房＋改名／只改名／只建房
- 分配方式：自動指派／手動指派／允許與會者選擇
- 一次性**引導式校準**（置頂小說明視窗，按 F8 記錄位置），之後不用重複校準
- 偵測 Zoom 版本與螢幕設定變化，變了會提醒你重新校準（僅提醒，不強制）
- 改名完成後檢查畫面是否異常，異常時建議重新校準
- 極簡無邊框深色視窗（金藍配色），四邊可拖拉縮放，預設在螢幕右下角
- 「檢查更新」：只在你按下選單時才連網，比對 GitHub 最新版並提醒，不會自動下載或覆蓋

## 需求
- Windows 10 / 11
- Python 3.10 以上（使用 exe 版則不需要）
- Zoom 桌面版（繁體中文介面測試過；其他語言只要位置相同也能用，因為是以座標操作）

## 安裝與啟動（原始碼版）
1. 安裝 [Python](https://www.python.org/downloads/)（安裝時勾選 *Add python.exe to PATH*）
2. 雙擊 `安裝套件.bat`（只需做一次，會安裝 `pyautogui`、`pyperclip`）
3. 雙擊 `啟動.bat`

## 免安裝 exe 版（不用裝 Python）
1. 到 [Releases](../../releases) 下載 `AIXAI-zoom-breakout-helper-vX.Y.Z-win64.zip`，解壓縮。
2. 雙擊資料夾裡的 `AIXAI-zoom-breakout-helper.exe`。
3. 清單、校準、紀錄會建立在 **exe 旁邊**，整個資料夾可以放隨身碟帶著走。

> 這類會模擬滑鼠鍵盤、且沒有數位簽章的程式，Windows SmartScreen 或防毒軟體可能跳出警告或誤判。程式碼完全公開，你可以自行檢視，或改用上面的原始碼版。每個 Release 都附有 SHA256 雜湊值，可用來核對檔案是否被改動。

自行打包：執行 `build.bat`（需要 Python），輸出在 `dist\`。

## 使用方式
### 第一次：校準
1. 在 Zoom 會議中打開「分組討論」。
2. 點視窗左上的 **☰** → **校準** → **完整引導校準**。
3. 依校準視窗的提示，把滑鼠移到指定位置後按 **F8**（筆電請按 **Fn + F8**）。選用的步驟可按 **Esc** 跳過；只想「改名」的話，必要的 4 項（房1名稱、改名鈕、確認鈕「是」、房2名稱）做完就夠。

> 校準座標與**螢幕解析度、縮放比例、Zoom 版本**綁定。換電腦或 Zoom 大改版後，需要重新校準。

### 每次使用
1. 選好清單、編輯房名（一行一間）。
2. 若選「建房」模式，先在 Zoom 打開「建立分組討論室」視窗。
3. 按 **▶ 執行**，手離開滑鼠，等它跑完。
4. 中途要停止：按 **Esc**，或把滑鼠甩到螢幕左上角。

## 資料存放位置
全部放在**程式旁邊**，整個資料夾可直接帶著走：

| 資料夾／檔案 | 內容 |
|---|---|
| `清單\*.json` | 每個清單＝房名＋建房方式＋分配方式（可用記事本編輯） |
| `資料\calibration.json` | 校準座標與校準當時的環境 |
| `資料\settings.json` | 等待時間、上次使用的清單、置頂 |
| `紀錄\` | 使用紀錄、環境變化紀錄 |

這些都是個人資料，已列入 `.gitignore`，不會被上傳。

## 已知限制
- 靠**畫面座標**操作：Zoom 介面改版、視窗位置或縮放改變，都可能需要重新校準。
- 不支援自動捲動：房間排到超出螢幕下緣的部分不會處理（請把分組視窗拉高）。
- 執行中請勿操作滑鼠與鍵盤。
- 若 Zoom 以系統管理員身分執行，本工具也需要以系統管理員身分執行，否則 Windows 會擋掉模擬輸入。
- 公司或學校管控的電腦可能禁止執行此類自動化工具。
